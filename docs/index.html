AUVBrain

Low-latency autonomous AUV agent loop with safety monitoring, telemetry, and offline-capable policy providers. This page explains the flow and shows reproducible benchmark outputs.

Repo: github.com/chandu1234678/AUVBrain

System Overview

The agent loop runs on a fixed cadence. Each tick: gather observations, decide a command (LLM optional), apply safety constraints, mix thrusters, and emit telemetry asynchronously.

Tick (Decision) Flow

  1. Read sensors/state (bounded timeout).
  2. Decide a command (Rules or LLM; timeout + fallback if enabled).
  3. Safety monitor validates/clips, and can force SAFE.
  4. Control computes thrust and mixes to 4-motor outputs.
  5. Write actuators (bounded timeout).
  6. Enqueue telemetry (non-blocking) and sleep to maintain cadence.
