AUVBrain

Low-latency autonomous AUV agent loop with safety monitoring, telemetry, and offline-capable policy providers. This page explains the flow and shows reproducible benchmark outputs.

Repo: github.com/chandu1234678/AUVBrain

System Overview

The agent loop runs on a fixed cadence. Each tick: gather observations, decide a command (LLM optional), apply safety constraints, mix thrusters, and emit telemetry asynchronously. 

flowchart LR
  Sensors[Sensors and State] --> Loop[Agent Loop] --> Policy[Policy] --> Safety[Safety Monitor] --> Control[PID + Mixing] --> Thrusters[Thrusters]
  Manual[Manual Override] --> API[FastAPI + WebSocket] --> Loop
  Loop --> Tel[Telemetry Writer] --> Log[Telemetry Log]

Tick (Decision) Flow

sequenceDiagram
  autonumber
  participant Loop as Agent Loop
  participant HW as Hardware
  participant Policy as Policy
  participant Safety as Safety Monitor
  participant Control as Control
  participant Tel as Telemetry

  Loop->>HW: Read sensors
  Loop->>Policy: decide command (timeout + fallback)
  Policy-->>Loop: VehicleCommand
  Loop->>Safety: Validate and clip
  Safety-->>Loop: Safe command
  Loop->>Control: Mix thrusters
  Control-->>Loop: Outputs
  Loop->>HW: Write actuators
  Loop->>Tel: Enqueue telemetry (async)
