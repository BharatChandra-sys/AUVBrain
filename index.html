AUVBrain

Low-latency autonomous AUV agent loop with safety monitoring, telemetry, and offline-capable policy providers. This page explains the flow and shows reproducible benchmark outputs.

Repo: github.com/chandu1234678/AUVBrain

System Overview

The agent loop runs on a fixed cadence. Each tick: gather observations, decide a command (LLM optional), apply safety constraints, mix thrusters, and emit telemetry asynchronously.

Tick (Decision) Flow

sequenceDiagram
  autonumber
  participant Loop as Agent Loop
  participant HW as Hardware (SIM/RPi)
  participant Policy as Policy Engine
  participant Safety as Safety Monitor
  participant Control as PID + Mixing
  participant Tel as Telemetry Writer

  Loop->>HW: read sensors and state (bounded timeout)
  Loop->>Policy: decide command (timeout + fallback)
  Policy-->>Loop: VehicleCommand
  Loop->>Safety: validate and clip (kill-switch)
  Safety-->>Loop: safe command
  Loop->>Control: compute thrust outputs
  Control-->>Loop: 4-motor mix
  Loop->>HW: write actuators (bounded timeout)
  par telemetry
    Loop->>Tel: enqueue telemetry event
  and
    Loop-->>Loop: sleep to maintain cadence
  end
